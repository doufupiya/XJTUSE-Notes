# XJTUSE-Notes

西安交通大学 软件工程 课程笔记存档 —— 哥在西安

云记里的手写笔记、实验报告、作业，导出成 PDF 后按学期和课程整理。给学弟学妹参考，请勿用于商业用途。

内容口径：只收课堂笔记、作业、实验报告、往年题目。**不含教材影印件，不含页脚标注「版权所有，请勿私自上传」的教师课件。**
